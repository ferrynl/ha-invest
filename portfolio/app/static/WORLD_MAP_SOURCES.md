# Local world map assets

Country geometry and multilingual names: Natural Earth 1:110m Admin 0 countries,
public domain. Source: https://github.com/nvkelso/natural-earth-vector/blob/master/geojson/ne_110m_admin_0_countries.geojson
Terms: https://www.naturalearthdata.com/about/terms-of-use/

Flags: flag-icons 7.6.0, MIT License; see flags/LICENSE.txt.
Source: https://github.com/lipis/flag-icons

Geometry uses an equirectangular projection, omitting Antarctica from the default
viewport. Smaller countries omitted from the 110m boundaries have point locations
where available; remaining countries stay in the list without an invented location.
All assets are served locally. No portfolio information is sent to a map provider.
