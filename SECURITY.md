# Security policy

## Supported versions

Security fixes target the latest published Home Invest release. Update your Home Assistant add-on before reporting an issue.

## Reporting a vulnerability

Please report vulnerabilities privately via GitHub's Security tab (Report a vulnerability), if enabled. Otherwise, open an issue requesting a private reporting channel, without including vulnerability details.

Include the affected version, reproduction steps, impact and relevant redacted logs. Never share access tokens, passwords, portfolio records, database backups or other personal information in public issues.

Do not test against installations you do not own. We will investigate reports and coordinate disclosure and fixes.
